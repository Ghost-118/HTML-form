# HTML Form

Proyecto enfocado en la estructuración de un formulario de retroalimentación de clientes utilizando **HTML5**. Demuestra el uso de controles de entrada para recopilar información de usuarios, validaciones nativas de campos y técnicas de accesibilidad en formularios web.

---

## 🚀 Características

- **Agrupación de Campos:** Uso de etiquetas `<fieldset>` y `<legend>` para estructurar secciones de datos personales, opciones de selección múltiple, botones de radio y listas desplegables.
- **Validación Nativa:** Implementación de atributos de HTML5 como `required`, `type="email"`, `type="number"`, `min` y `max`.
- **Diversidad de Controles:** Uso de casillas de verificación (`checkbox`), botones de opción (`radio`), selectores desplegables (`<select>`) y áreas de texto de formato libre (`<textarea>`).
- **Accesibilidad:** Uso sistemático de la etiqueta `<label>` enlazada a cada campo mediante el atributo `for`.
